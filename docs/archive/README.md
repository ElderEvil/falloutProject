# Archive

Historical reference material, kept because it still records a decision, a superseded contract, or the
state a feature was designed against. Nothing here guides current implementation: current contracts live in
`docs/features/`, `docs/backend/` and `docs/frontend/`.

Rule: `docs/features/` is a working set. When a doc is superseded, or a proposal has no scheduled work,
move it here — or delete it when its content already lives in a GitHub issue or PR — and repoint live links.
